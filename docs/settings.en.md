# Settings

App startup and the interface theme. Opened with the gear button at the right of the top bar; the website address is `#settings`.

## General

Only in the installed Windows app; on the website the switches are disabled, with a note next to them.

- "Launch with Windows" — the app opens when you sign in to Windows.
- "Start in tray" — the window does not open on launch, the app goes straight to the tray.
- "Always run as administrator" — the combo tracker, ping and FPS need administrator rights. Takes effect on the next launch.
- With both on, autostart uses a Windows Task Scheduler task with the highest privileges, so Windows does not ask for permission at sign-in.

## Display

"Key hints" — how skill keys are labeled in the tracker and the combo schema: Shift as a word, "Sh" or a picture; LMB and RMB as a word or a picture of the two mouse buttons; W/A/S/D as letters or arrows ↑/←/↓/→.

## Theme

Five interface themes, like the in-game interface theme setting: "Classic", "Season: Summer", "Season: Winter", "Season: Spring" and "Land of the Morning Light".
A theme changes the window title bar, the decoration above it and the close button. Hover over a theme to preview it.
It works on the website and in the app, and the choice is remembered between launches.
