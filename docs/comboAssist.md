# Помощник комбо

Своё комбо для класса и подсказка поверх игры, какое умение жать следующим.

Редактор работает и на сайте, а следить за игрой и показывать подсказку поверх неё умеет только программа
для Windows (см. [Оверлей](overlay.md)).

## Редактор

- Слева — «Класс» и «Сохранённые комбо». Комбо привязано к классу и подходит всем его персонажам.
- «Умения» — список умений класса с поиском и стойками «Наследие», «Пробуждение» или «Все».
- Выберите ячейку и кликните умение слева: после него появится новая ячейка, а над списком — «Дальше можно»:
  что обычно идёт следом, связки отмечены.
- Перетащите иконку на другую ячейку, чтобы поменять их местами. ПКМ по ячейке — «Удалить ячейку»,
  «Вставить слева», «Вставить справа».
- **«Связка»** — умение жмётся сразу после предыдущего, иначе цепочка сорвётся.
- **«Опциональный»** — оверлей его не подсказывает, но если применить, комбо продолжится с него.
- **Развилки** — «Сделать развилкой» и «+ ветка»: несколько вариантов продолжения, подсказка выбирает по
  перезарядкам. Развилку можно связать с прошлой: вошли во вторую ветку — дальше подсказка тоже по второй.
- **«Филлеры»** — умения, которые оверлей предлагает, пока следующий шаг на перезарядке.
- Редактор предупреждает о пустых ячейках и о продолжении связки без её запуска.

## Тренировка

Режим «Тренировка» — проверить комбо без игры: клик по иконке «применяет» умение, «Применить подсказанное»
и «Ошибиться» показывают, как подсказка поведёт себя в игре, «Сначала» начинает комбо заново.

## Импорт и экспорт

- «Экспорт комбо» — файл `.json` с названием комбо, чтобы поделиться с другими игроками.
- «Импорт комбо» — добавить комбо из таких файлов.

## В игре

«Следить за игрой» (только программа для Windows) — программа читает «Историю испол. навыков» на экране
и ведёт по комбо:

- **«Схема комбо»** — всё комбо с отмеченным текущим шагом, вертикально или горизонтально;
- **«Следующие умения»** — «Сейчас» и что дальше, с клавишами персонажа; если шаг на перезарядке —
  «Через N с» и «Пока ждёшь» с филлером;
- если применили умение не по порядку, подсказка продолжает с него; если связка оборвалась — подсказывает,
  как в неё войти заново.

Окно игры — «Полноэкранный в окне». Программа только читает экран: в игру не вмешивается и клавиши не жмёт.

> [!NOTE]
> Справочник умений берётся из открытых данных [bdolytics.com](https://bdolytics.com), поэтому нужен интернет.

<details>
<summary>Где хранятся комбо</summary>

- Программа для Windows — `Документы\Black Desert\BDO Tools\comboAssist\combos.json`, общий для всех аккаунтов:
  комбо — про класс, а не про аккаунт. Там же `watch.log` — что программа увидела на экране.
- Сайт — в хранилище браузера.
