# README совпадает с приложением

`README.md` в корне — лицо репозитория для игроков: что такое BDO Tools, что умеет каждая тулза, где запустить
сайт и скачать программу для Windows. Он пишется для пользователя, а не для разработчика: без имён классов
и модулей, кроме короткого раздела «Для разработчиков» в конце.

## Два языка

README два: `README.md` (русский) и `README.en.md` (английский). Сверху у каждого — переключатель языка.

- Любая правка — сразу в обоих файлах, в том же изменении. Файлы зеркальны: те же разделы в том же порядке,
  те же скриншоты (каждый — снятый на языке файла), ссылки и команды.
- Названия вкладок, кнопок и пунктов меню — как в интерфейсе на языке файла: русский — `values/strings.xml`,
  английский — `values-en/strings.xml` (заметки там — «labels», контроли — «crowd controls», «Пресеты в игре» —
  «In-game presets» и т. п.). Пути — `Документы\Black Desert` и `Documents\Black Desert`.
- Оговорка о Pearl Abyss в английском файле — дословно `app_disclaimer` из `shared/.../values-en/strings.xml`
  (без последней фразы про файлы настроек).
- Новый язык интерфейса не требует нового README: хватает двух.

## Как читается

README должен читаться быстро, поэтому держи его устройство:

- наверху — таблица ссылок (сайт, установщик) и плашки `> [!IMPORTANT]` про закрытую игру и `>` про то, что
  меняются только файлы настроек; затем оглавление;
- у тулзы — одна фраза «зачем», скриншот и короткие блоки по смыслу (`### Подраздел` или **жирный заголовок**),
  в блоке — список пунктов по одной мысли; длинные абзацы разбивай на пункты;
- подробности, нужные редко (пути к папкам BDO Tools), — в `<details>`;
- путь к папкам BDO Tools всегда полный: `Документы\Black Desert\BDO Tools`, а не `Black Desert\BDO Tools`,
  чтобы не искали в папке, куда установлена игра.

## Когда проверять

Перед тем как закончить задачу, сравни дифф с README. Править README нужно, если изменение:

- добавляет, удаляет или переименовывает тулзу или вкладку (`AppTab`, подписи `tab_*` в `strings.xml`);
- меняет, что тулза умеет: новая или удалённая возможность, другой файл игры, который она читает или пишет,
  другое условие («закройте игру», «только Chromium»);
- добавляет или убирает язык интерфейса (`AppLanguage`);
- меняет платформы, браузеры, способ установки или обновления настольной версии, адрес сайта или имя установщика
  (`DESKTOP_INSTALLER_URL`, `.github/workflows/*.yml`);
- меняет команды сборки и запуска из `CLAUDE.md`, перечисленные в разделе «Для разработчиков»;
- заметно меняет вид экрана, который есть на скриншоте.

Внутренние правки — рефакторинг, тесты, исправление ошибки без смены поведения, мелкие отступы и цвета —
README не трогают. Если не уверен, перечитай README целиком и ищи фразу, которая после изменения стала неправдой.

## Как править

1. Найди в README все места, которые противоречат новому поведению (описание тулзы, список возможностей,
   таблица платформ, установка). Исправь их, а не дописывай рядом второе описание.
2. Новая тулза — новый раздел `### <Название вкладки>` в «Что умеет»: одна фраза, зачем она игроку,
   и список возможностей. Удалённая тулза — убери раздел и её скриншот.
3. Пиши как в интерфейсе: README на русском, поэтому названия вкладок и кнопок — как в русском
   `values/strings.xml`. Список языков интерфейса в README совпадает с `AppLanguage`: добавили или убрали
   язык — поправь его. Пути к файлам игры — от папки
   `Документы\Black Desert`.
4. Не обещай того, чего нет в коде. Не добавляй планы и «скоро».
5. Сторонняя иконка или картинка под лицензией с указанием авторства (CC BY, например game-icons.net) — строка
   об авторе, источнике и лицензии в конце README, над оговоркой. Удалили ассет — удали и строку.
6. Оговорка о Pearl Abyss в конце README не меняется: её формулировку требует руководство по фан-контенту
   (та же, что `app_disclaimer` в `shared/.../strings.xml`).

## Скриншоты

Лежат в `docs/screenshots/` (PNG или WEBP). Имя — как модуль фичи (`portraitConstructor`, `uiEditor`), общий экран —
по смыслу (`accounts`), экран внутри тулзы — `<модуль>-<что>` (`uiEditor-skillPicker`, `uiEditor-apply`).
У каждого скриншота две версии: `<имя>.png` — интерфейс на русском, для `README.md`; `<имя>.en.png` — тот же экран
на английском, для `README.en.md`. README ссылается на них относительными путями.

Скриншотов должно хватать, чтобы увидеть каждую заметную возможность, а не только главный экран тулзы.

- **Новая заметная возможность** (окно, панель, режим — окно выбора умений, окно применения, превью импорта) —
  её скриншот входит в ту же задачу: сними его на обоих языках и вставь в оба README рядом с её блоком.
  Не ограничивайся текстом и не оставляй это «на потом»: если снять не выходит, скажи пользователю, каких
  скриншотов не хватает.
- **Изменился вид экрана со скриншота** — пересними обе версии.
- **Как снять.**
  - Нужен браузер, где сайт получил доступ к папке игры: во встроенном браузере приложения выбор папки не
    срабатывает, поэтому снимай через Claude in Chrome (скилл `chrome-browser`) — в Chrome или Яндекс Браузере
    пользователя, с его согласия. Запусти dev-сервер `webApp-wasm`, открой `http://localhost:8080` в новой вкладке;
    если папка ещё не выбрана, пользователь сам нажимает «Выбрать папку» — системный диалог сам не проходи.
  - Окно — 1440×900 (`resize_window`). Перед снимком уведи курсор с нужной области (`hover` в пустое место),
    если только наведение не нужно для подсказки. Снимай `computer` → `zoom` с `save_to_disk: true` и `scale: 1`:
    весь экран тулзы или окно; файл появится в `tool-results` сессии — скопируй его в `docs/screenshots/`.
  - Язык переключается кнопкой `RU` / `EN` в верхней панели. Сними все экраны на одном языке, переключи и сними
    те же экраны с той же раскладкой, потом верни язык, который был.
  - Чтобы показать окно, которое появляется после правки (например, «Применить в игру»), правь только в редакторе
    и **никогда не подтверждай запись в игру**: закрой окно «Отменой», отмени правку и проверь, что «Применить в игру»
    снова неактивна.
  - Окно выбора аккаунта видно, только когда аккаунтов несколько. Если у пользователя один, с его согласия сделай
    временные моки: папки `UserCache\9990001` и `UserCache\9990002` в `Документы\Black Desert`, в каждой один
    `gamevariable.xml` только со строками `<CharacterOrderList CharacterNo="…" Order="…"/>` с номерами его настоящих
    персонажей (тогда подтянутся портреты) и старой датой изменения (`touch -d "3 days ago"`). Аккаунты читаются при
    старте, поэтому перезагрузи страницу (`location.reload()`); язык для второй версии меняй через `localStorage`
    `bdo-tools-language` (`ru` / `en`) и снова перезагружай. Аккаунт-мок не выбирай; после съёмки удали обе папки,
    верни язык и проверь, что окно выбора больше не появляется.
  - Окна настольной версии снять нельзя — тогда запусти её (`./gradlew :desktopApp:run`) и попроси пользователя.
- **Личные данные.** На снимках — портреты, заметки и аккаунт пользователя. Прежде чем класть файл в репозиторий,
  покажи его пользователю и положи только после согласия.
- Новый файл клади вместо старого с тем же именем (или под новым именем по правилу выше) и поправь ссылки в обоих
  README; ставший ненужным старый файл удали.
- Пока нового скриншота нет, оставь старый и скажи пользователю, что он устарел или что для возможности скриншота
  ещё нет, — не удаляй и не выдумывай.

## Чек-лист

- [ ] `README.md` и `README.en.md` изменены вместе и совпадают по разделам;
- [ ] каждая вкладка из `AppTab` (кроме заглушек) описана в README, и наоборот;
- [ ] возможности тулз, условия и ограничения в README совпадают с кодом и строками интерфейса;
- [ ] ссылки на сайт, установщик и релиз рабочие и совпадают с кодом и workflow;
- [ ] скриншоты показывают текущий вид экранов, у каждой заметной возможности есть свой на обоих языках (или пользователю
      сказано, каких не хватает).
