# Запуск от имени администратора

Касается только настольной версии (`jvm("desktop")`). На сайте прав нет: `isRunningAsAdmin()` всегда `false`.

## Зачем права

BlackDesert64.exe запущен с правами администратора. Windows не даёт процессу с обычными правами доступ к такому
процессу и к части системных функций. Без прав программа работает, но:

| Что | Почему нужны права | Где в коде |
|---|---|---|
| Трекер комбо слышит клавиши | ввод окна игры Windows отдаёт только процессу с теми же правами или с UIAccess; без них `RawInputListener` работает, но нажатий нет | `game-overlay`, раздел «Клавиши» |
| Точный пинг | включить сбор `GetPerTcpConnectionEStats` для подключения игры может только администратор (`SetPerTcpConnectionEStats` → 5); без прав — `PingReading(needsAdmin = true)` и «— мс» | `feature/gameInfo/.../DesktopGamePingSource` |
| FPS и 1% low | ETW-сессию реального времени (`PresentTrace`) запускает только администратор; без прав включатель недоступен и объяснён | `feature/gameInfo/.../PresentTrace` |
| Путь процесса игры | путь процесса администратора Java не видит — игра ищется по имени через `CreateToolhelp32Snapshot` | `GameProcess.kt` |

Скриншоты экрана игры, окна поверх игры и файлы в `Документы\Black Desert` прав не требуют. Окна поверх
полноэкранной игры — отдельная история: им нужен не администратор, а UIAccess (память проекта,
`uiaccess-fullscreen-overlay`).

## Как проверить права

- `isRunningAsAdmin()` из `platform/composable` (`composable.overlay`, `IsUserAnAdmin` из shell32). Права процесса
  во время работы не меняются — проверку можно запомнить (`remember { isRunningAsAdmin() }`).
- `isGameElevated()` — запущена ли игра от администратора (значок кнопки оверлея со щитком).
- Функция, которой нужны права, не прячется: без прав её включатель недоступен (`enabled = false`), а рядом
  написано, почему и что сделать (запустить программу от имени администратора или включить настройку ниже).

## Щиток в верхней навигации

`AdminBadge` в `shared` — золотой щит перед названием программы, только когда она запущена от администратора.
Подсказка `admin_badge_hint` перечисляет, что дают права. Новая функция, которой нужны права, — допиши её в эту
строку на всех языках и в таблицу выше.

## Настройки запуска (экран «Настройки» → «Основное»)

Фича `feature/settings`: `StartupInteractor` → `StartupRepository` → `WindowsSystemStartup` (`desktopMain`).
Путь к exe — `System.getProperty("jpackage.app-path")`; при запуске из Gradle его нет, и настройки недоступны.

| Настройка | Как устроена |
|---|---|
| «Всегда запускать от имени администратора» | флаг совместимости `~ RUNASADMIN` в `HKCU\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers`, имя значения — путь к exe. Как галочка «Совместимость» в свойствах файла: UAC при каждом запуске. Действует со следующего запуска, в том числе после самообновления (exe на том же месте) |
| «Запускать вместе с Windows», без прав | строка `BDO Tools` = `"<путь>"` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| «Запускать вместе с Windows», с правами | задача планировщика `BDO Tools`: «при входе пользователя», `RunLevel Highest` — стартует от администратора без вопроса UAC. Строки `Run` с правами администратора Windows при входе не запускает, поэтому строка удаляется |

- Создать и удалить задачу с наивысшими правами может только администратор: без прав PowerShell-скрипт
  (`Register-ScheduledTask` / `Unregister-ScheduledTask`) идёт через `Start-Process -Verb RunAs` — пользователь видит
  окно UAC. Отказ в UAC — не ошибка: после записи настройки перечитываются из системы, и включатель показывает
  то, что получилось на самом деле.
- Скрипты передаются через `-EncodedCommand` (Base64 от UTF-16LE): так пробелы и кавычки в пути не ломают команду.
- Смена «от администратора» перестраивает и автозапуск (строка `Run` ↔ задача), поэтому `apply` пишет обе настройки.
- Реестр — `Advapi32Util` из jna-platform (приходит из `platform/composable`), а не `reg.exe`.

## Чего не делать

- Не перезапускай программу с правами сама и не проси UAC без действия пользователя: окно UAC появляется только
  в ответ на включатель.
- Не пиши в `HKLM` и в `Program Files`: программа ставится для текущего пользователя, права на запись туда не нужны.
- Не полагайся на права в общем коде: всё, что зависит от них, — в `desktopMain` и проверяется `isRunningAsAdmin()`.
