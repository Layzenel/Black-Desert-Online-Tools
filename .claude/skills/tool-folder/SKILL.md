# Всё своё — в `Black Desert\BDO Tools\<модуль>\<аккаунт>`

Папка `Документы\Black Desert` принадлежит игре. BDO Tools пишет в неё только два вида файлов:

- **файлы игры, которые тулза меняет по просьбе пользователя:** `FaceTexture\<персонаж>.bmp`,
  `UserCache\<аккаунт>\gamevariable.xml`, `UserCache\<аккаунт>\11\<персонаж>\gamevariable.xml`,
  `UserCache\<аккаунт>\gameVariable_lobby.xml`;
- **всё остальное, что создаёт само приложение,** — только внутри `Black Desert\BDO Tools\`.

Новых папок и файлов в корне `Black Desert` и в папках игры (`FaceTexture`, `UserCache`, `Customization` и т. д.)
тулзы не создают.

## Как устроена `BDO Tools`

Первый уровень — папка модуля фичи с тем же именем, что у модуля (`feature/portraitConstructor` →
`portraitConstructor`, `feature/uiEditor` → `uiEditor`). Второй — папка аккаунта (номер папки в `UserCache`).
Внутри — папки по назначению.

```
Black Desert\BDO Tools\
├── portraitConstructor\<аккаунт>\       конструктор портретов
│   ├── FaceTexture_backup\<дата-время>\  резервные копии портретов
│   ├── Favorite FaceTexture\<дата-время>\ избранное
│   ├── Current portraits\                <персонаж>.bmp — портрет без заметки и значков, <персонаж>.txt — заметка и значки
│   └── lobby_backup\<дата-время>.xml     копии gameVariable_lobby.xml перед синхронизацией заметок
└── uiEditor\<аккаунт>\                  редактор интерфейса
    ├── backups\                          копии gamevariable.xml аккаунта и персонажей перед записью
    ├── presets\*.json                    «Мои пресеты»
    └── background\image                  подложка
```

## Правила

1. **Путь — `BDO Tools\<модуль>\<аккаунт>\<что>\…`.** Новая тулза с собственными данными заводит папку с именем
   своего модуля. Данные, общие для нескольких тулз, — отдельная папка в `BDO Tools` с понятным именем;
   сначала спроси пользователя.
2. **Всё по аккаунтам.** Общего между аккаунтами в папке тулзы нет: даже то, что можно было бы делить
   (пресеты, подложка), пользователь решил держать у каждого аккаунта своим. Перенос между аккаунтами — через
   экспорт и импорт. Без аккаунта (`account = null`, в `UserCache` нет списка персонажей) — папки прямо
   в `BDO Tools\<модуль>\`. Подробно — скилл `multi-account`.
3. **Аккаунт передаётся явно** в каждый метод хранилища (`*Storage`, JS-мост), который читает или пишет
   файлы тулзы. Хранилище собирает путь в одном месте (`area(...)` / `tool(account)`), а не в каждом методе.
4. **Перенос при смене места.** Если данные лежали в другом месте, при первом открытии аккаунта они переносятся:
   - где аккаунт известен (папка с его номером, имя файла `gamevariable_<аккаунт>_…`, файл портрета персонажа
     этого аккаунта) — в папку этого аккаунта, остальное — в аккаунт, который открыли;
   - ничего не перезаписывается: совпавшее имя получает суффикс `_2` или файл остаётся на старом месте;
   - опустевшие старые папки удаляются.

   Перенос лежит в отдельном файле рядом с хранилищем: `LegacyPortraitFolders.kt`, `LegacySlotsFolders.kt` (Desktop),
   `adoptLoose` в `*BridgeScript.kt` (браузер). Старые места, которые уже переносятся:
   `Black Desert\FaceTexture_backup`, `Black Desert\Favorite FaceTexture`, `BDO Tools\portraits`,
   `BDO Tools\lobby_backup`, `BDO Tools\slots`.
5. **Обе платформы — одни пути.** Desktop (`java.nio.file`, `*Storage` в `desktopMain`) и сайт (JS-мост
   `*BridgeScript.kt`) пишут в одни и те же папки. Перемещать папки File System Access API не умеет —
   в браузере перенос делается копированием файлов и удалением старых. В мосте не больше двух аргументов:
   аккаунт склеивается с именем строкой `аккаунт/файл`.
6. **Пути в текстах** — от `Black Desert`: «BDO Tools\portraitConstructor\<аккаунт>\FaceTexture_backup\…».
   В `strings.xml` обратный слэш пишется как `\\`, угловые скобки — `&lt;` `&gt;`. В shell и `node -e`
   двойные обратные слэши схлопываются — правь такие строки инструментом Edit.
7. **Тесты.** На новое место хранения — тест хранилища на временной папке (`desktopTest`): файлы появляются
   в `BDO Tools\<модуль>\<аккаунт>\…`, у другого аккаунта их не видно, старые переносятся, старых папок не остаётся.

## Чек-лист

- [ ] код ничего не создаёт в корне `Black Desert` и в папках игры, кроме изменения файлов игры по просьбе пользователя;
- [ ] новые данные — в `BDO Tools\<модуль>\<аккаунт>\…`, имя папки модуля совпадает с модулем;
- [ ] старые данные из прежнего места переносятся при первом открытии, без потерь, на обеих платформах;
- [ ] на это есть тесты;
- [ ] README (раздел «Несколько аккаунтов»), `strings.xml`, KDoc и дерево выше в этом скилле называют новое место.
